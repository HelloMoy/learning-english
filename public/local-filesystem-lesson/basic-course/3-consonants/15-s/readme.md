# /s/

🔊 El sonido /s/ es una consonante sorda que se produce al empujar aire por un espacio estrecho entre la lengua y el paladar. No se usan las cuerdas vocales. Es un sonido claro y agudo — ¡como el silbido de una serpiente! 🐍

🔊 The /s/ sound is a voiceless consonant made by pushing air through a narrow space between the tongue and the roof of the mouth. You don’t use your vocal cords. It's crisp and sharp — like a snake hissing! 🐍
