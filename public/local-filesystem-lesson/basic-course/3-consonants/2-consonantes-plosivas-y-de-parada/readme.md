# Consonantes Plosivas y de Parada

🗣️ Las consonantes plosivas (o de parada) se producen al detener el flujo de aire y luego liberarlo. Al inicio de las palabras, estas consonantes suelen tener una explosión clara (plosivas). Al final de las palabras, a veces el sonido se detiene sin una liberación audible (consonantes de parada).
Ejemplos: /p/, /b/, /t/, /d/, /k/, /g/

🗣️ Plosive consonants (or stops) are sounds produced by stopping the airflow and then releasing it. When these sounds occur at the beginning of words, they’re usually fully released with a burst of air (plosives). At the end of words, the release might be weaker or absent (stops).
Examples: /p/, /b/, /t/, /d/, /k/, /g/
