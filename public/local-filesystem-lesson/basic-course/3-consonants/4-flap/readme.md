# /Flap/

El flap /ɾ/ es un sonido rápido en el inglés americano, parecido a una “d” suave y corta.
Ocurre cuando la lengua toca ligeramente el techo de la boca (los alveolos).
Lo escuchamos en palabras como better, butter, city, party, donde la “t” o “tt” no se pronuncia como una T fuerte, sino como una D rápida.
