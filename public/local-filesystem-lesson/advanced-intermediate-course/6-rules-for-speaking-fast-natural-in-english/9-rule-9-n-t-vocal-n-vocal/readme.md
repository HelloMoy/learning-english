# Rule # 9 : N+T+Vocal = N+Vocal

## 🇪🇸 Español

### Regla 9: N + T + vocal = N + vocal

Cuando una /t/ queda **entre una /n/ y una vocal**, los americanos simplemente la eliminan.

> _interview_ → “inerview” · _twenty_ → “tweny” · _internet_ → “inernet”

Es una de las razones por las que el inglés americano te suena distinto al que estudiaste. Entender esta regla te desbloquea decenas de palabras que ya conocías pero no reconocías al oírlas.

## 🇺🇸 English

### Rule 9: N + T + Vowel = N + Vowel

When a /t/ sits **between an /n/ and a vowel**, Americans simply drop it.

> _interview_ → “inerview” · _twenty_ → “tweny” · _internet_ → “inernet”

It's one of the reasons American English sounds different from the English you studied. Understanding this rule unlocks dozens of words you already knew but couldn't recognize by ear.
