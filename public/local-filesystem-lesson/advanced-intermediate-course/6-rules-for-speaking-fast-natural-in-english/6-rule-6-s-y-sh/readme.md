# Rule # 6: S+Y = SH

## 🇪🇸 Español

### Regla 6: S + Y = SH

Cuando una /s/ va seguida del sonido /y/, las dos se funden en /ʃ/ — el “sh” de _shoe_.

> _this year_ → “thi-shear” · _miss you_ → “mi-shu”

No es pereza ni mala pronunciación: es la forma correcta de decirlo rápido. Si separas los dos sonidos, suenas artificial.

## 🇺🇸 English
