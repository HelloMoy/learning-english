# Rule # 5: T+ Y = CH

## 🇪🇸 Español

### Regla 5: T + Y = CH

Cuando una /t/ se encuentra con el sonido /y/, las dos se funden en /ʧ/ — el “ch” de _chocolate_.

> _don't you_ → “don-cha” · _get you_ → “ge-cha”

No es pereza ni mala pronunciación: es la forma correcta de decirlo rápido. Si separas los dos sonidos, suenas artificial.
